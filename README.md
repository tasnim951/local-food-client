# Foodian

Live Site: [https://your-live-site-url.com](https://your-live-site-url.com)

## About

Foodian is a simple and easy-to-use food review website where users can find and share their opinions about different foods. The website is designed to be friendly for everyone, with features that help you explore food reviews and manage your own.

## Features

- Users can register and login to get a personalized experience.
- Logged-in users can add, edit, and delete their own food reviews.
- Responsive design works well on both desktop and mobile devices.
- User profile dropdown menu for easy access to personal pages.
- Clean and modern layout with a smooth navigation bar and logo.
